# 实验四 V1：安全攻防对抗

入口：`/experiments/security`。默认使用 `VITE_DATA_SOURCE=mock npm run dev`（不设置时也默认 Mock）。页面提供案例选择、训练/考核模式、阶段、遥测面板、自动告警、学生判断、隔离/恢复处置、复盘、历史与 JSON 报告。

## 案例与通道

- **遥测重放**：运行先收集正常对照样本；异常阶段在专属实验订阅通道重放其中一个有效快照，保留该快照的原序列号与采集时间。检测器比较运行内序列、接收时间和数据年龄，生成重复/倒退/过期等证据。隔离后不再把旧帧应用到实验状态。
- **遥测链路退化**：支持低/中/高三档服务端受控延迟、采样丢弃和高档短时中断，不接受脚本。接收间隔与序列跳变可计算时显示实测值；其他缺失率/指标保持“未知”。最后观测会保留并标记过期。
- 这里的“链路”仅指 **Gateway 到当前实验页面的独立遥测通道**。页面订阅中断不等于飞控失联；本实验不验证或宣称验证 ArduPilot 失联保护。
- 开始实验不会 ARM、起飞或发送飞行命令。注入仅改写/调度发往该运行 WebSocket 的数据副本，不修改 `VehicleState`、MAVLink 上行、普通 `/ws/telemetry`、其他实验或飞行停止通道。

## 状态与资源

阶段顺序为准备 → 正常对照 → 异常运行 → 恢复验证 → 完成；另有中止/失败结束状态。运行使用独立 `runId`、案例版本 `1.0`、模式、难度和种子。Mock 与 API 均在运行创建时生成种子并记录；训练模式案例固定，观测由该运行内确定性时序产生。考核案例由服务端基于运行种子选择，触发时机由 Gateway 隐藏；运行响应不会返回隐藏字段。学生在对照阶段的非“正常”判断单独记为误报，不与自动告警混为一谈。

“隔离”状态按已提交、已接受、已执行、已验证展示。API 只有收到至少 3 条序列递增、未过期的实时帧才接受恢复验证。API 延迟调度最多只有当前 WebSocket 处理协程中的一个在途样本；停止时重置序列基准，并在等待返回后复核运行状态，禁止发送已取消的延迟样本。结束/中止/失败都会停止注入、释放订阅并保存报告。重复动作与相同判断请求 ID 幂等。刷新后仅依据 Gateway 运行状态恢复；进行中的非准备阶段无法安全恢复时会中止清理，不使用浏览器旧遥测续跑。

## 检测与评分

自动检测只使用会话通道样本和接收元数据，不读取案例答案/注入计划。证据包括序列重复/倒退、数据过期、页面订阅中断、接收间隔扩大及恢复。断线重连明确开始新序列基准，避免把合法序列重置当作重放。采集时间来自样本、接收时间由通道生成、耗时由运行基准计算。

规则版本 `security-score-v1`，总分 100：判断与证据 30、发现及时性 15、处置合理性 25、恢复验证 20、复盘 10。异常判断错误/未提交不获判断分；没有有效证据降低判断项；对照误报每次扣 5 分、最多扣 15 分；没有执行隔离或恢复验证不获相应分；复盘不少于 20 字才获得复盘分。重复请求不会重复记录或计分。API 分数由 Gateway 根据实际运行、判断事件和证据计算并持久化；Mock 使用同一评分含义，但标记为模拟成绩。

报告包含 runId、模式、案例版本、难度、种子、事件时间线、检测证据、学生判断、处置状态、恢复耗时字段、分项成绩、扣分理由和限制说明，可导出 JSON。API 报告保存到 Gateway 现有 `MUVA_PLATFORM_DATA` 持久化文件的 `securityRecords` 项。

## Mock 与 API

- **Mock**：使用确定性的前端教学数据，可离线体验页面和评分，不代表真实车辆数据。
- **API**：要求真实 Gateway/车辆心跳可用；不可用时明确失败，不回退到 Mock。REST `/api/v1/security/runs...` 管理运行和服务端评分；专用 `WS /ws/security/{runId}` 使用独立 `security.telemetry.v1` 事件契约。普通 telemetry `1.0` envelope 不接收安全事件。
- 可用根目录 `./start_all_muva.sh` 启动完整项目，再打开 `/experiments/security`；仅体验模拟流程时在前端目录执行 `npm run dev`。

## 限制与安全说明

Gateway 当前没有真实身份认证/授权，前端用户名不可信；UUID 也不是访问控制。API 考核可以由有网络/API 访问权的使用者伪造身份或调用接口，因此不构成正式防篡改考试。不得将 Gateway 暴露到不可信公网。该实验不评价飞行任务完成率、飞控防御效果或真实网络攻击阻断效果。API 专用通道使用当前 Gateway 的最新解码快照采样，丢包率只在序列数据可比时估算；真实环境端到端链路与 SITL 安全性仍需独立实测。
