# 实验一场景地图联动

步骤7使用 MapLibre + Esri World Imagery 在线卫星地理瓦片，按步骤3确认的场景 HOME 经纬度加载，可以拖动和缩放。不是步骤3的静态预览照片，也不是把一张照片贴在地图上。最高请求层级为19，更高缩放复用地理瓦片。卫星影像不是实时拍摄，实时内容是无人机相对位移和飞行轨迹。

原 `tile.openstreetmap.org` 在当前环境返回访问限制，CARTO 返回密钥提示，Esri 栅格街道地图在校园高层级无覆盖，简化矢量地图视觉过于抽象；现改用覆盖四个场景的卫星地理瓦片。地图只有收到瓦片内容后才标记为已加载；失败时明确显示“离线坐标示意，不是地理底图”，并提供重试。Mock 核心飞行训练不依赖在线底图服务；在线底图需要互联网连接，生产部署需要核对供应商使用条款和额度。

## 坐标职责

- `configuration.homePosition` 是步骤3确认的起飞点，决定第一次进入步骤7的地图中心。
- `telemetryStore.mapHome` 是 Service 确认的飞控 HOME，用于实际航线基准。实验一使用明确标注的场景相对坐标视图：将实际 HOME 映射到所选 HOME，将无人机、航迹、规划航点按真实东/北位移绘制到场景。只转换展示数据，不改写 Store 原始 GPS、Service 数据、飞控 HOME 或飞行任务。
- 场景 HOME 与实际 HOME 相距超过5米时，地图显示“场景相对坐标 · 飞控原点已映射”；悬停可查看差异说明。这不是绝对 GPS 位置，不能用于真实环境导航。实时监控等非实验场景视图仍使用绝对 GPS 坐标。
- 场景地图点击航点时，将展示坐标反向转换成实际飞控坐标再写入航线 Store，上传仍使用实际飞控 HOME 与航点，避免误向所选场景的远程绝对位置飞行。
- 无有效连接、心跳或实时位置时隐藏无人机标记和实时数值，不把默认位置当作当前遥测。
- 无人机标记使用四旋翼图形。未飞离实际 HOME 时显示在所选场景 HOME；实际飞离后按真实相对位移移动。无人机定位、HOME定位、轨迹定位和刷新场景定位不会跳回校园 SITL 坐标。无人机在场景视野外时仍提供边缘定位图标。
- 未取得飞控 HOME 时允许查看场景，但禁止执行自定义航线，可以重新读取 HOME。

## 生命周期

地图视角通过 `flightMapView` 保存到现有实验进度。视角键由进度ID、场景ID及配置 HOME 经纬度组成；同一实验返回或刷新时恢复中心与缩放，遥测更新不会强制居中。场景切换、HOME变更或重新开始会清理旧视角、轨迹、航点。

遥测地图请求和订阅有独立代次校验；断开、清理或更换 Session 后的旧请求不能写回新实验。实验地图快照只接收本次开始时间之后、带有效时间戳的轨迹点。Gateway `/vehicle` 轨迹秒级时间戳由 API Service 转为领域层的毫秒。

当前 API 的地图快照接口没有 Session 标识；前端以请求上下文和本次开始时间隔离缓存，但无法验证同时运行的其他服务端 Session。未来服务端应支持 Session 级 HOME/轨迹接口。当前 `start_iris_sitl.sh` 仍以固定校园坐标启动 SITL，Gateway 的 runtime/start 只连接现有环境，没有按场景重新创建 SITL；本次场景相对坐标展示不声称修复该真实初始化限制。

## 重新创建环境

现有步骤8“重新开始实验一”操作停止当前环境并清除当前浏览器关联的服务端进度，返回步骤1；步骤4再次创建时产生新 Session。已保存的历史报告不清除。仅切出并返回实验不会重新创建环境，也不重置当前地图或训练。

## 验证

`npm test` 包含四场景 HOME 定位、修改 HOME 后视角失效、视角持久化、HOME 差异、不修改遥测坐标、旧快照及订阅失效、时间戳筛选、断线恢复、新实验清理航点以及异步航线取消测试。在线底图的网络可用性需在目标浏览器中验证。

`tests/experiment1-map-browser.cjs` 使用 Chromium 在独立 Mock 实例中验证所选 HOME 居中、校园实际 HOME 的场景映射、不改写遥测、拖动缩放、视角恢复、断网重试和重开始。地图瓦片由测试图片替代，步骤1～6使用定向教学夹具；不是完整教学流程或真实后端飞行验收。

浏览器检查是可选任务，不要求日常 Mock 运行安装浏览器测试依赖。先启动独立实例 `VITE_DATA_SOURCE=mock npm run dev -- --host 127.0.0.1 --port 5181 --strictPort`，再执行 `npm run test:experiment1-map-browser`。环境需提供 `playwright-core` 和 Chromium；可通过 `PLAYWRIGHT_CORE_PATH` 指定模块路径、`CHROMIUM_PATH` 指定浏览器路径、`MUVA_TEST_URL` 指定测试实例地址。不要将它指向正在使用的真实 API 实例。

`node tests/experiment1-geographic-map-browser.cjs` 额外验证四个场景的真实在线卫星瓦片、所选 HOME 居中、校园 SITL 原点映射，以及所有定位按钮不跳回校园。截图位置可用 `MUVA_SCREENSHOT_DIR` 指定。此脚本使用 Mock 和教学步骤夹具，不执行 API 飞行命令；截图需人工检查，HTTP 200 本身不证明地图内容正确。
