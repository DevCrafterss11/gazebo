## 设计规范

### 无人机图标
- 使用专业四旋翼SVG图标（参考实验1）
- 图标包含：机身框架 + 四个旋翼
- 颜色动态绑定：`#18baff`, `#3ee7b1`, `#ffb547`, `#b994ff`, `#ff728d`

### 地图场景
- 底图：校园训练场景
- 坐标系：WGS84 / ENU
- 场景范围：中心 500m

### 航线规划
- 分配策略：区域均分、垂直分块
- 航线类型：往返式覆盖（奇数行反向）
- 航线显示：不同颜色区分，虚线连接
- 从起点出发，经过任务区，返回起点的闭环

### 交互设计
- 顶点可见性：半径8px，描边3px
- 点击热区：30像素范围
- 矩形绘制：显示实时提示
- 工具栏：清晰的操作反馈

## 实现要点

1. **严格参考设计图**：UI实现应1:1还原设计图的布局、颜色、间距
2. **使用真实DOM组件**：禁止使用设计图截图作为背景
3. **保持视觉一致性**：复用全局样式token和组件
4. **确保可访问性**：语义化结构、键盘操作、ARIA标签
